# 快捷键地图

macOS 原生快捷键可视化工具：读取当前前台 App 菜单中公开的快捷键，用虚拟键盘高亮，并显示组合键对应的作用。

## 当前能力

- 自动跟踪最近使用的前台 App；
- 通过 Accessibility API 读取菜单快捷键；
- 按修饰键组合过滤；
- 虚拟键盘高亮与作用列表；
- 搜索动作、组合键和菜单路径；
- 每条结果标明来源，不推测未知快捷键。
- 按住 `⌃⌥Space` 显示非激活玻璃浮层，松开立即隐藏；
- 唤起使用 macOS 系统热键注册，不需要“输入监控”权限；
- 浮层从虚拟键盘按键引线到“App + 作用”标签；
- 浮层右侧按修饰键分组展示全部已识别快捷键，不静默截断；
- 目录先按 `全局`、`当前 App`、`输入法` 区分来源，再按修饰键组合分组；
- 微信输入法启用时，读取本机 MMKV 配置，展示可验证的语音输入快捷键（支持单独修饰键及 `Fn + Space`）；
- 支持 App 专属规则，当前内置 `ChatGPT：⌃⇧M → 切换模型`。

## 构建

```bash
chmod +x scripts/build_app.sh
./scripts/build_app.sh
open "dist/快捷键地图.app"
```

首次启动需要在“系统设置 → 隐私与安全性 → 辅助功能”中授权。

仅用于界面开发和自动化验证时，可以执行：

```bash
open -na "dist/快捷键地图.app" --args --demo --overlay-demo
```

## 已知边界

- 只能自动读取 App 菜单向 Accessibility API 公开的快捷键；
- 网页、编辑器模式和未出现在菜单中的内部快捷键可能缺失；
- 全局快捷键目录尚未接入，后续按明确来源逐类支持。
